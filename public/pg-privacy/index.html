PageGrade Privacy Policy

Last updated: July 2026

Data Collection

PageGrade does not collect, store, transmit, or share any personal data. All SEO analysis runs entirely on your device within your browser.

Permissions

activeTab — Used to read the current page's HTML (title, meta tags, headings, links, images) solely for the SEO audit. The extension only runs when you click its icon.

scripting — Used to inject the audit code into the current tab on demand. No scripts run automatically.

storage — Used only to save your license key and Pro preference locally. This data never leaves your device.

License Verification

When you enter a license key, the extension sends it directly to Lemon Squeezy's public API (api.lemonsqueezy.com) to validate it. No other data is sent.

Third-Party Sharing

PageGrade does not sell, share, or transfer any user data to third parties.

Changes

If this policy changes, the extension will be updated and the new version noted here.
